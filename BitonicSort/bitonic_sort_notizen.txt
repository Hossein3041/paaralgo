Exkurs Hypercube - Graphentheorie:
- Sei k > 0 eine natürliche Zahl. Menge V bestehe aus allen k-stelligen Binärzahlen => V {(bk, ... b1) : bi <- {0,1}}.
- Menge E wird aus allen ungeordneten Paaren von Elementen u,v als Element von V gebildet, die sich genau an einer Stelle unterscheiden.
- Graph G = (V, E) heißt Hypercube Qk (Hyperwürfel)
-> Q1: {0,1}
-> Q2: {00,01,10,11}
-> Q3: {000,010,100,110,001,011,101,111}
- Bitonisches Mischen lässt sich auf Hypercube abbilden
=> Daraus entsteht ein weiter Sortieralgorithmus

Bitonische Folgen:
- Folgen ganzer Zahlen {X0, X1, ..., X2n-1} mit Elementen xi (0 <= i <=2n-1) bitonisch,
wenn gilt:

1. Es gibt ein k (0 <= k <= 2n-1) mit der Eigenschaft
x0 <= x1 <= ... <= xk => xk+1 => ... => x2n-1
- Einfach ausgedrückt: Die linke Hälfte sortiert sich von klein/gleich nach gropß/gleich bis k.
- Die rechte Hälfte sortiert sich kleiner/gleich von k+1. Beispiel:
1,2,7,8,10,9,8,-2,-4
- x0 = 1; xk = 10; x2n-1 = -4

- Anmerkung: xk muss nicht in der Mitte sein, kann auch am Anfang stehen oder am Ende.

2. Die Folge selbst erfüllt zwar nicht die Bedingung, aber sie kann durch "zyklisches Schieben"
in eine Form gebracht werden, die 1 erfüllt.

Beispiele bitonischer Folgen:
- {1,2,4,5,8,7,6,3} => x0 = 1, xk = 8, x2n-1 = 3
- {8,9,6,3,1,2,4,5} => zyklisches Schieben => {1,2,4,5,8,9,6,3} => x0 = 1, xk = 9, x2n-1 = 3
- {6,3,1,2,4,5,8,7} => zyklisches Schieben => {1,2,4,5,8,7,6,3} => x0 = 1, xk = 8, x2n-1 = 3
- Anmerkung: Eine bitonische Folge muss auch eine gerade Länge haben

Eigenschaften bitonischer Folgen:
- Bitonische Folgen gerader Länge haben die Eigenschaft:
-> Seien {x0,x1,...,x2n-1} eine bitonische Folge,
-> Seien mi := min(xi,xn+i) bzw. Mi := max(xi,xn+i), (0 <= i <= n-1), dann gilt:

1. Die Folgen {m0,m1,...,mn-1} und {M0,M1,...Mn-1} eind ebenfalls bitonische Folgen und
2. max(m0,m1,...,mn-1) <= min(M0,M1,...Mn-1)

Hier zunächst ein paar **Tipps**, wie du das **Bitonic Merge–Sort** (ohne erst `makeBitonic()` zu implementieren) auf einem **8-Knoten-Hypercube** realisieren kannst – **ohne** direkt Code zu schreiben:

---

## 1. Grundgerüst aus Sicht eines Knotens

Jeder Knoten $P_i$ (mit $i$ von 0 bis 7) hält genau **einen Wert** $x_i$. Die Knoten kommunizieren paarweise über einen Barrier-Sync in **log₂(8)=3** Stufen:

```
for (stage = 3; stage ≥ 1; stage--) {
    // 1) Partner ermitteln: bitflip
    // 2) Vergleichsrichtung festlegen (min oder max)
    // 3) Wert austauschen und ggf. swap durchführen
    // 4) Barrier
}
```

1. **Partner finden**

   * In Stufe $d\in\{3,2,1\}$ flippt jeder Knoten sein $(d-1)$-tes Bit in der Binäradresse:

     $$
       \text{partner} = i \;\oplus\; 2^{\,d-1}.
     $$
   * Beispiel $i=3$ (011):

     * $d=3$:(flip MSB) $011\oplus100=111$ → Partner=7 (Abstand 4)
     * $d=2$:(flip 2. Bit) $011\oplus010=001$ → Partner=1 (Abstand 2)
     * $d=1$:(flip LSB) $011\oplus001=010$ → Partner=2 (Abstand 1)

2. **Richtung („take-min“ vs. „take-max“) bestimmen**

   * In einer **Merge-Phase** einer bitonischen Folge sortierst du:

     * Die Knoten in der „unteren“ Hälfte ($i < 2^{d-1}$) holen sich das **kleinere** von $\{x_i,x_{\text{partner}}\}$,
     * die „obere“ Hälfte ($i ≥ 2^{d-1}$) das **größere**.
   * Alternativ (netzwerkweit) nutzt du ein Bit in $i$, z.B.

     ```
     if ((i & 2^{d}) == 0)   // i in aufsteigender Hälfte
         takeMin();
     else
         takeMax();
     ```

3. **Austausch und Vergleich**

   * Sende deinen Wert an `partner`, empfange dort dessen Wert.
   * Vergleiche beide und behalte min oder max entsprechend der Phase.
   * Barrier, damit alle Knoten synchron weiterfahren.

4. **Rekursion vs. Iteration**

   * Für **BitonicMerge** brauchst du *keine* Rekursion, wenn du die 3 Stufen iterativ durchläufst (weil der Input schon bitonisch ist).
   * **BitonicSort** obenauf würde zuerst `sort(erste Hälfte)`, `sort(zweite Hälfte)`, `reverse zweite Hälfte` und dann einmal `BitonicMerge` aufrufen.

---

## 2. Pseudocode-Analyse

### 2.1 Algorithmus 2.17 **BITONICMERGE**

**Deutsch**

> **Eingabe:** Eine bitonische Sequenz $S=\langle a_1,\dots,a_n\rangle$ (Länge $n=2^k$).
> **Ausgabe:** $S$ in aufsteigender Reihenfolge.

1. **Basisfall:**
   Wenn $\lvert S\rvert=1$, dann ist schon sortiert → zurückgeben.
2. **Paralleles „Compare & Swap“**
   Für $i = 1\ldots n/2$ gleichzeitig:

   ```
   if (a_i > a_{i + n/2})
       swap(a_i, a_{i + n/2]);
   ```
3. **Teilen in zwei Bitonic-Folgen**

   * $S_1 = \langle a_1,\dots,a_{n/2}\rangle$
   * $S_2 = \langle a_{n/2+1},\dots,a_n\rangle$
4. **Rekursion**

   * $S'_1 \leftarrow \text{BITONICMERGE}(S_1)$
   * $S'_2 \leftarrow \text{BITONICMERGE}(S_2)$
5. **Konkatenation**

   * Rückgabe von $S'_1\|\;S'_2$

**Kernidee:**
Durch den ersten parallelen Schritt sichert man, dass alle Elemente der „unteren“ Hälfte am Ende ≤ alle der „oberen“ Hälfte sind. Die beiden Hälften bleiben bitonisch und werden rekursiv sortiert.

---

### 2.2 Algorithmus 2.18 **BITONICSORT**

**Deutsch**

> **Eingabe:** Beliebige Sequenz $S$ der Länge $n=2^k$.
> **Ausgabe:** $S$ in aufsteigender Reihenfolge.

1. **Wenn $|S|>1$:**
2. Teile $S$ in zwei Hälften:

   * $S_1=\langle a_1,\dots,a_{n/2}\rangle$,
   * $S_2=\langle a_{n/2+1},\dots,a_n\rangle$.
3. Sortiere beide Hälften rekursiv:

   * $S'_1=\text{BITONICSORT}(S_1)$ (aufsteigend)
   * $S'_2=\text{BITONICSORT}(S_2)$ (aufsteigend)
4. Wandle $S'_2$ in **absteigend** um (Reverse → $S''_2$).
   ⇒ $S'_1\|\;S''_2$ ist **bitonisch** (erst auf-, dann absteigend).
5. Führe **BITONICMERGE** auf dieser bitonischen Folge aus und gib das Ergebnis zurück.

### 4. Zusammenfassung der Implementierungstipps

1. **Threads/Knoten**
   Jeder Knoten $i$ führt exakt die gleichen (oblivious) Schritte aus:

   * Ausrechnen des Partners
   * Decide min/max anhand Bit-Tests
   * Austausch (zwei Barrier)
2. **Barrier/Synchronisation**
   Pro Abstandsstufe genau **zwei** Barrier-Aufrufe:

   * Nach dem Senden, vor dem Compare/Swap
   * Nach dem Compare/Swap, bevor nächste Stufe beginnt
3. **Bit-Manipulation**
   Nutze `int partner = i ^ (1 << (d-1));`
4. **Iterative statt rekursive Merge**
   Weil der Input bitonisch ist, genügt eine Schleife über Stufen. Erst wenn du später `makeBitonic()` ergänzen willst, benötigst du die komplette `BITONICSORT()`-Rekursion.

import java.util.concurrent.BrokenBarrierException;
import java.util.concurrent.CyclicBarrier;

class ODD_EVEN_SWAP extends Thread{
    int N; int process_ID; int my_Value;
    ODD_EVEN_DATA[] m_Data;
    CyclicBarrier m_Barrier;
    public ODD_EVEN_SWAP(int N, int id, int myvalue, ODD_EVEN_DATA[] data, CyclicBarrier barrier){
        this.N = N;
        this.process_ID = id;
        this.my_Value = myvalue;
        this.m_Data = data;
        this.m_Barrier = barrier;
    }

    public void sendToRight(int value){
        if(process_ID < N - 1)
            m_Data[process_ID + 1].setFromLeft(value);
    }

    public int receiveFromRight(){
        return m_Data[process_ID].getFromRight();
    }

    public void sendToLeft(int value){
        if(process_ID > 0)
            m_Data[process_ID - 1].setFromRight(value);
    }

    public int receiveFromLeft(){
        return m_Data[process_ID].getFromLeft();
    }

    @Override
    public void run(){
        for(int i = 0; i < N; ++i){
            boolean amLeft = ((i + process_ID) % 2 == 0);

            if(amLeft && process_ID < N - 1)
                sendToRight(my_Value);
            else if(!amLeft && process_ID > 0)
                sendToLeft(my_Value);
            
            try{
                m_Barrier.await();
            } catch (InterruptedException | BrokenBarrierException e) {
                Thread.currentThread().interrupt();
                System.err.println("Thread " + process_ID + " Synchronisationsfehler.");
                return;
            }

            if(amLeft && process_ID < N - 1){
                int other_Value = receiveFromRight();
                my_Value = ODD_EVEN_DATA.min(my_Value, other_Value);
            } else if(!amLeft && process_ID > 0) {
                int other_Value = receiveFromLeft();
                my_Value = ODD_EVEN_DATA.max(my_Value, other_Value);
            }

            try{
                m_Barrier.await();
            } catch (InterruptedException | BrokenBarrierException e) {
                Thread.currentThread().interrupt();
                System.err.println("Thread " + process_ID + " Synchronisationsfehler.");
                return;
            }
        }
    }

    public int getSortedValue(){
        return my_Value;
    }
}


public class ODD_EVEN_DATA{
    private int fromLeft;
    private int fromRight;

    public synchronized  void setFromLeft(int val){
        this.fromLeft = val;
    }

    public synchronized  int getFromLeft(){
        return fromLeft;
    }

    public synchronized void setFromRight(int val){
        this.fromRight = val;
    }

    public synchronized int getFromRight(){
        return fromRight;
    }

        return (a < b) ? a : b;
    }

    public synchronized static int max(int a, int b){
        return (a > b) ? a : b;
    }
}

import java.util.concurrent.CyclicBarrier;
import java.util.concurrent.BrokenBarrierException;
public class BitonicSortMain{
    /** Array mit allen Prozessoren (Zugriff über Index = Prozess-ID) */
    private static BitonicSortThread[] processes;
    public static void main(String... args){
        int P = 8;              // 8 Processes
        final int STAGES = 3;   // log2(8) = 3 Merge-Stufen
        int[] m_Array = new int[]{2,5,6,10,8,7,4,1};    // Bitonische Folge aus Paper
        CyclicBarrier barrier = new CyclicBarrier(P);   // Barrier für Synchronisation
        processes = new BitonicSortThread[P];   // Thread-Array anlegen

        printArray(m_Array, "Array unsortiert");
        
        for(int i = 0; i < processes.length; ++i){    // Thread-Objekte erzeugen: process_id, zu sortierender Wert, Stages als Anzahl der Schritte, sowie barriere
            processes[i] = new BitonicSortThread(i, m_Array[i], STAGES, barrier);
        }

        for(int i = 0; i < processes.length; ++i){  // Thread-Objekte starten
            processes[i].start();
        }

        for(int i = 0; i < processes.length; ++i){  // Thread-Objekte joinen: Auf Beendigung aller Threads warten
            try{
                processes[i].join();
            } catch(InterruptedException e){
                Thread.currentThread().interrupt();
                System.err.println("Warten auf Thread " + i + " unterbrochen");
                break;
            }
        }

        // Sortierten Wert zurücklegen
        for(int i = 0; i < m_Array.length; ++i){
            m_Array[i] = processes[i].getSortedValue();
        }

        printArray(m_Array, "Array sortiert");
    }
    /** Array ausgeben */
    public static void printArray(int[] array, String message){
        System.out.println(message);
        for(int i = 0; i < array.length; ++i){
            System.out.print(array[i] + "\t");
        }
        System.out.println();
    }

    /** Innere Thread-Klasse */
    static class BitonicSortThread extends Thread{
        
        private final int process_ID;   // Eigene Prozess-ID im Netzwerk
        private int my_Value;           // Eigener aktueller Wert
        private final int m_Stages;     // Gesamtanzahl der Merge-Stufen
        private final CyclicBarrier m_Barrier;  // Barrier für Synchronisation
        private volatile int partner_Value;       // Empfangener Wert vom Partner

        public BitonicSortThread(int processID, int myValue, int stages, CyclicBarrier barrier){
            this.process_ID = processID;
            this.my_Value = myValue;
            this.m_Stages = stages;
            this.m_Barrier = barrier;
        }
        /** Wert an Partner schicken */
        private void sendMyValue(int partnerID, int myValue){
            processes[partnerID].setOtherValue(myValue);
        }
        /** Vom Partner aufgerufene Methode zum Setzen des Werts */
        private synchronized void setOtherValue(int val){
            this.partner_Value = val;
        }
        /** Eigenen Empfangspuffer auslesen */
        private int receivePartnerValue(){
            return partner_Value;
        }
        /** Min oder Max nehmen, abhängig vom boolean */
        public int getRightValue(int a, int b, boolean min){
            return min ? (a < b ? a : b) : (a > b ? a : b);
        }

        @Override
        public void run(){
            for(int stage = m_Stages; stage >= 1; --stage){
                
                int partner_ID = computePartner(stage);
                boolean takeMin = isAscendingPhase(stage);

                sendMyValue(partner_ID, my_Value);

                awaitAtBarrier();

                int received_Value = receivePartnerValue();

                my_Value = getRightValue(my_Value, received_Value, takeMin);

                awaitAtBarrier();
            }
        }

        /** Berechnet den Partner pro Stage per Bitflip */
        private int computePartner(int stage){
            int distance = 1 << (stage - 1);
            return process_ID ^ distance;
        }

        /** True, wenn Prozessor in der unteren Hälfte liegt */
        private boolean isAscendingPhase(int stage){
            int distance = 1 << (stage - 1);
            int blockSize = distance << 1;
            return (process_ID % blockSize) < distance;
        }
        /** Synchronisationspunkt */
        private void awaitAtBarrier(){
            try{m_Barrier.await();}
            catch(InterruptedException | BrokenBarrierException e){
                Thread.currentThread().interrupt();
                System.err.println("Thread " + process_ID + " Synchronisationsfehler.");
            }
        }
        /** Gibt den final sortierenden Wert zurück */
        public int getSortedValue(){
            return my_Value;
        }
    }
}
