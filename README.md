# parallele algorithmen

Im Rahmen des Multicore-Praktikums im Modul Parallele Algorithmen,
durchgeführt unter fachlicher Betreuung von Prof. Dr. Thomas Umland,
wurden rechenintensive Algorithmen systematisch für Multicore-Architekturen
entworfen, implementiert und analysiert.
Der Schwerpunkt lag auf der Parallelisierung von Sortier- und Merge-Algorithmen
unter Verwendung von Threads in Java.
Es wurden sowohl sequentielle als auch nebenläufige Varianten implementiert,
inklusive Thread-Synchronisation, Barrieren und Work-Splitting-Strategien.
Zur Bewertung der Implementierungen wurden Laufzeitmessungen auf Mehrkernsystemen
durchgeführt und Kennzahlen wie Speedup und Effizienz in Abhängigkeit von der
Threadanzahl analysiert.
Ziel war es, ein fundiertes Verständnis für Skalierbarkeit, Parallelisierungsgrenzen
und Performance-Optimierung auf Multicore-Systemen zu erlangen.
